# Glossary

> Canonical definitions. Articles use these meanings.
> To change or add a term, edit this file in its own commit and note it in the PR.

| Term | Definition |
|---|---|
| GPU-hour | One GPU used for one hour. The standard unit for pricing GPU compute. |
| Spot price | The price for compute available now, with no term commitment. |
| Term contract | A commitment to buy compute for a fixed period (e.g. 1 month, 1 year) at an agreed price. |
| Forward / futures | A contract to buy or sell compute at a set price for delivery at a future date. |
| OCPI | Ornn Compute Price Index. See `ornn.md` for scope and methodology. |
| Index | A published benchmark price built from observed transactions or quotes under a stated methodology. |
| Neocloud | A cloud provider focused on renting GPU compute, as opposed to a general-purpose hyperscaler. |
| Hyperscaler | A large general-purpose cloud provider. |
| Utilization | Share of available GPU capacity that is rented or in use over a period. |
| GPU-backed financing | Debt secured by GPUs or by the contracted revenue they generate. |
| Power capacity | Grid or on-site electricity available to a data center, in MW. |
